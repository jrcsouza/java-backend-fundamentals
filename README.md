# Java Backend Fundamentals

Repositório dedicado à construção progressiva da base de engenharia de software em Java, focado em lógica de
programação, boas práticas e resolução de problemas algorítmicos.

---

## 🎯 Objetivos de Formação

Este projeto é o alicerce para a construção de um perfil Backend competitivo no mercado, desenvolvendo na prática:

- Lógica de programação e raciocínio para resolução de problemas
- Sintaxe e fundamentos da linguagem Java
- Estruturas de dados (Vetores, Matrizes e Collections)
- Programação Orientada a Objetos (POO)
- Boas práticas de programação (Clean Code)

*Nota: Os tópicos avançados (Banco de Dados, APIs REST e Spring Boot) gerarão repositórios independentes no futuro,
mantendo a arquitetura deste repositório focada exclusivamente no núcleo do Java.*
