# Java Backend Fundamentals

Repositório dedicado à construção progressiva da base de engenharia de software em Java, focado em lógica de
programação, estruturas de dados, Programação Orientada a Objetos, boas práticas e preparação para desenvolvimento
Backend.

## 🎯 Objetivos de Formação

Este projeto é o alicerce para a construção de uma formação sólida em Java Backend, desenvolvendo progressivamente:

* Lógica de programação e raciocínio para resolução de problemas
* Sintaxe e fundamentos da linguagem Java
* Estruturas condicionais e repetitivas
* Vetores e Matrizes
* Estruturas de dados e Collections
* Programação Orientada a Objetos (POO)
* Encapsulamento, composição, herança, polimorfismo e interfaces
* Tratamento de exceções
* Generics
* API moderna de Data e Hora
* Programação funcional, Lambda e Stream API
* Manipulação de arquivos
* Testes automatizados
* Clean Code e princípios de engenharia de software
* Git e GitHub
* SQL e banco de dados relacional
* Desenvolvimento de APIs REST
* Spring Boot e ecossistema Spring
* Persistência com JPA/Hibernate e Spring Data JPA
* Segurança com Spring Security e JWT
* Docker e ambientes containerizados
* CI/CD
* Cloud
* Mensageria e processamento assíncrono
* Cache com Redis
* Observabilidade
* Arquitetura de aplicações Backend

*Nota: O objetivo deste repositório é consolidar o núcleo do Java e os fundamentos necessários para Backend. Tecnologias
de banco de dados, frameworks, infraestrutura e arquitetura serão aprofundadas em repositórios próprios.*

## 🧭 Estratégia de Formação

> Este repositório não tem como objetivo acumular centenas de exercícios. O objetivo é construir competência
> progressivamente e transformar conhecimento em capacidade de desenvolver sistemas.

A formação utilizará quatro tipos principais de prática:

* **Beecrowd:** desenvolvimento de lógica e resolução de problemas.
* **Desafios práticos:** problemas criados especificamente para aplicar os conceitos em situações próximas de sistemas
  reais.
* **Projetos:** integração de vários conceitos em aplicações completas.
* **Revisões e refatorações:** retorno a códigos antigos para melhorar organização, legibilidade, testes e design.

> A quantidade de exercícios de cada módulo será proporcional à complexidade do conteúdo. Conteúdos simples terão
> menos exercícios, enquanto POO, Collections, Streams, testes e Backend terão maior quantidade de práticas e
> projetos.

---

## 🧠 Princípios da Mentoria

> A formação será conduzida de maneira progressiva. O objetivo não é simplesmente terminar cursos ou marcar
> exercícios como concluídos, mas desenvolver autonomia para resolver problemas e construir aplicações.

Durante a formação:

* Cada novo conceito será estudado antes de ser utilizado em um projeto maior.
* Exercícios serão selecionados de forma estratégica, evitando repetição desnecessária.
* Erros serão analisados e corrigidos, não apenas substituídos por uma solução pronta.
* Projetos serão reutilizados e evoluídos conforme novos conhecimentos forem adquiridos.
* Tecnologias avançadas serão introduzidas somente quando os fundamentos necessários estiverem consolidados.
* O foco será compreender **por que** uma tecnologia é utilizada, não apenas aprender sua sintaxe.
* A evolução será registrada no GitHub para formar um histórico real de aprendizado.
* O objetivo final será conseguir desenvolver, testar, documentar, executar e publicar aplicações Backend.
