# 🏆 Metodologia de Aprendizado

Os exercícios não serão tratados apenas como uma lista de problemas a serem resolvidos.

Cada exercício será utilizado para desenvolver uma habilidade específica.

### Níveis de domínio

- 🟢 **Reproduzir** — consegue aplicar o conceito apresentado na aula.
- 🔵 **Aplicar** — consegue resolver um problema semelhante sozinho.
- 🟡 **Adaptar** — consegue modificar a lógica para uma situação diferente.
- 🟠 **Resolver** — consegue analisar um problema novo e criar uma solução.
- 🔴 **Dominar** — consegue explicar, implementar e adaptar o conceito.

### Regra da mentoria

A quantidade de exercícios não é o objetivo.

O objetivo é desenvolver a capacidade de:

> **Entender o problema → criar a lógica → implementar em Java → testar → corrigir → explicar a solução.**

Exercícios considerados repetitivos poderão ser pulados, enquanto novos desafios poderão ser adicionados quando
necessário para reforçar algum conceito.
